# Travel Reels Videos Directory

Drop your vertical 9:16 `.mp4` travel reel videos directly in this folder:
`F:\New folder\ahilk-portfolio\public\videos\reels\`

### Suggested Filenames:
- `kashmir.mp4` -> Referenced as `/videos/reels/kashmir.mp4`
- `ladakh.mp4` -> Referenced as `/videos/reels/ladakh.mp4`
- `rajasthan.mp4` -> Referenced as `/videos/reels/rajasthan.mp4`
- `meghalaya.mp4` -> Referenced as `/videos/reels/meghalaya.mp4`
- `spiti.mp4` -> Referenced as `/videos/reels/spiti.mp4`
- `varanasi.mp4` -> Referenced as `/videos/reels/varanasi.mp4`

You can customize video paths in `src/app/travel/data/reels.ts`.
Until local files are added, fallback web-streamed sample videos and high-res posters will automatically display.
